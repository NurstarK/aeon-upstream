# ISS-001 — autoresearch misconfigured (var=Agents)

## Summary
`autoresearch` runs daily (`0 7 * * *`) with `var: "Agents"`. No skill named
`Agents` exists — closest matches are `agent-buzz` and `agent-displacement`.
The skill aborts cleanly (no variations, no PR), so `cron-state.json` logs
`success` while the skill accomplishes nothing. This has recurred on
2026-10-05 and 2026-10-06.

## Evidence
- `memory/logs/2026-10-05.md` — "ABORTED — skill not found. No skills/Agents/SKILL.md exists."
- `memory/logs/2026-10-06.md` — same abort; flagged as likely misconfigured schedule.
- `memory/cron-state.json` — `autoresearch.last_status: "success"` despite the abort.

## Suggested fix
Edit `aeon.yml` line 97 to point `var` at a real skill directory, e.g.:
`autoresearch: { enabled: true, schedule: "0 7 * * *", var: "agent-buzz" }`
(or `agent-displacement`). Alternatively disable autoresearch until a target is chosen.

## Owner
Repair loop (skill-repair / operator). Requires a one-line `aeon.yml` change.
